Read the scope first

These numbers apply only to the exact measured configurations in this snapshot. They do not certify unmeasured models, hardware, topologies, workloads, or deployments.

  • Client-observed TTFT and TPOT are reported separately.
  • Multi-node configurations are excluded from this first public view.
  • No pass/fail threshold is applied to the accuracy values.

Definitions

How to read the metrics

MAPE
Mean absolute percentage error across matched operating points. Lower is closer, but this page does not define a universal release threshold.
Shape error
Error after normalizing each measured and predicted curve at its lowest shared concurrency. It describes curve behavior independently of absolute scale.
Evidence
Successful predictions divided by selected measured operating points. A missing or failed prediction never counts as accuracy evidence.

Evidence boundary

Accuracy is not the support matrix

This page reports end-to-end serving accuracy for matched measurements. Forward-pass accuracy and strict-native estimator coverage are separate evidence lanes and must not be used to turn an unmeasured end-to-end configuration into a supported claim.
