`SlidingWindowSpec`, `SlidingWindowMLASpec` and `KpoolTailSpec` declare `extra_retained_tokens` with the default zero. The tail inherits that default. The adapter requires the actual integer zero on every layer spec of a group. An absent or nonzero value remains unresolved. `attention_chunk_size` must be absent or `None`. Only an `MLAAttentionSpec` with role `INDEXER` can have a `storage_block_size` other than its block size. The adapter records that storage block as the kernel block of the layer.

These cases stay unsupported. The adapter reports them by name and never relabels them:

- `ChunkedLocalAttentionSpec`.
- `RSWASpec`. Its manager frees the blocks between the prompt and the decode window, and no cache kind models that.
- `HiSparseHotSpec` and `HiSparseResidentSpec`.
- `EncoderOnlyAttentionSpec` and `CrossAttentionSpec`.
- Any other spec class.
- A uniform group whose inner specs map to different kinds.
- HiSparse placement. A group with `host_resident` true, a role other than `DEFAULT` or `enable_kv_transfer` false leaves `cache.groups` unresolved. So does a host-resident tensor. One device pool is modeled.

This pin rejects speculative groups and unsupported alias layouts. Runtime source checks include the selected backend module. To select another backend, audit and declare its implementation. Do not claim that these inspected backends cover it. A vendor patch that changes a declared file produces unresolved evidence with the actual hash retained. After you inspect such a patch, update the source notes, mapping tests and manifest in a fresh campaign attempt.

The vLLM hashes come from the source tarball of the pinned revision. The GLM-5.3-Flash producer pins 17 vLLM files of its image in `runtime/glm53flash/runtime-source-sha256.json`. Each of them equals the tarball file, so the hashes stand for the stock `v0.31.0` image. The Dynamo hash is that of `components/src/dynamo/vllm/instrumented_scheduler.py` at `395f02405c1dd1835ab73a39f7a5984ae5fd4552`, the Dynamo update for vLLM 0.31.0. It is not the scheduler of the producer overlay (Dynamo `54960177`), because that scheduler reads `Scheduler.skipped_waiting`, which vLLM 0.31.0 removed. Every declared hash stays provisional until the live GLM-5.3-Flash probe checks it against the probe image. `vllm/_version.py` is declared after that probe reads it.
