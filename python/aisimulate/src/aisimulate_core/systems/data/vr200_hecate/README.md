# Hecate VR200 GLM-5.2 NVFP4 pilot

This data supports the bounded default op-level decode pilot and one opt-in SGLang graph-prefill profile, `sglang_glm52_nvfp4_vr200_tp4_graph_v1`, on a four-GPU Hecate VR200 node (SM107). The graph profile's immutable ID is `829a83e1629ba546dd4bd90e75a2e2496b7fb24ddc8b60dfbf076ba02312cbce`. Use the canonical [`RustForwardPassPerfModel.best_available`](../../../../../../../docs/core-api.md#vera-rubin-glm-52-graph-prefill-pilot) constructor; select the graph profile only for its direct `predict_prefill_latency` method.

The exact runtime is SGLang `0.5.18+nvinternal.rubin.0.8full.66997102`, source commit `02c5a855aceb968c310e6fbc6632270e26edc84b`, OCI image index `sha256:53299500a280c8de34bd484507a45b2f83b4d5e7c999b77284fa31930f7e63ab`. The checkpoint is `nvidia/GLM-5.2-NVFP4`, with config SHA-256 `d3783a603e5aa9cb58eff7a5d8ac9c42d83156b229efe185c72e9e2dc8444923` and quantization-config SHA-256 `212394aabaa6a4e7823668e7a03d6295422aa2ca2cbdbfbfc519eab602ad20e6`. The profile binds TP4/MoETP4/EP1, PP1, attention DP1, FP8 KV, BF16 projections, deterministic FlashInfer top-k, forced DSA and breakable prefill graphs. Full source/runtime identity, native launch arguments, qualifications and external evidence hashes are retained in the identical profile sidecars beside both composite tables.

The bundle has 1,023 rows across seven parquet tables: 518 GEMM, 88 MoE, 304 DSA context, 84 DSA generation, 14 all-reduce, seven joint attention sequences and eight communication/norm boundaries. The original five tables and hardware YAML remain byte-identical to the accepted input bundle. The packaged [publication receipt](../../prefill_graph_publications/sglang_glm52_nvfp4_vr200_tp4_graph_v1.json) records the output hashes; the two profile sidecars bind every composite row's exact Float64 payload and the original table/YAML hashes.

The DSA rows came from [job 445688753's source artifact](https://gitlab-master.nvidia.com/dl/jet/ci/-/jobs/445688753/artifacts/file/workspace/logs/basic/aisim-vr-dsa-projection-recollect/jet_log.zip). In that ZIP, `jet_log.yaml` contains `workload.spec.script`; decoding its `VR_PAYLOAD` yields the source archive with SHA-256 `74c9cea7bf54efda4ae967fe8af4847bf5531d4e53fa65e6ded1f91700badff4`. The archive has no `.git`, so the collection metadata references the producing artifact instead of an inferred repository commit. Its 51-file `collector.sglang_rubin.collect_mla_module` closure reproduces the recorded `sha256:95fde0cd25cd058a03572855c2f0795683b3c225d47b0a729d49a28065a506ec`; this historical hash intentionally differs from the current collector source. Both DSA parquet files remain byte-identical to that job's outputs.

The attention sequence measures the complete 78-layer attention pattern once (21 full indexers and 57 index-reuse layers). Communication/norm rows measure separate post-attention and following-MLP boundaries, applied 78 and 77 times respectively. These are isolated measured proxies with declared limitations; the full profile documents the synthetic attention state and repeated communication-block methodology. The consumer uses exact keys, rejects incomplete or altered profiles, and applies no full-forward correction or fitted scale.

The [combined accuracy report](../../../../../../../docs/vr200-glm52-accuracy.md) contains all seven prefill and 18 decode results, the canonical API examples, measurement boundary and evidence hashes. All seven prefill mean forward latencies satisfy the original ±15% criterion, with worst absolute error 5.23%. Default op-level decode satisfies that criterion in 17/18 cases; the initial pilot accepts the remaining observed −17.09% error at batch 1 and K=1,024. Decode uses no prefill graph selector or observed-MoE distribution override. Native references are comparison evidence and never inputs to the prediction.

The opt-in prefill profile's seven-context qualification is unchanged; its direct API takes total input length in `isl`, including the cached prefix. The decode comparison covers one forward step per exact batch/KV shape, with all 15 aligned rank-maximum samples retained. Its single independently reviewed acquisition does not establish repeatability across independent runs.

These bounded comparisons do not cover scheduler TTFT, end-to-end TPOT, model quality, arbitrary shapes or general Vera Rubin support. The hardware profile also contains assumptions: its HBM and network peaks are inferred, and empirical memory coefficients fit seven standalone graph RMSNorm points with about 33% maximum residual.
