## Contents and compatibility boundary

- Base image remains `nvcr.io/nvidia/ai-dynamo/sglang-runtime-nightly@sha256:cc84ea52fc8e66fb61a54692a30b2dcfa4d9b2349aa39d565039657cba8c26bb`.
- SGLang base remains `71de97b264b04dcd514cf904003028aefe9775c8`.
- Backport the FPM changes from [SGLang PR #38711](https://github.com/sgl-project/sglang/pull/38711), revision `ed18d64951b93ac252d921ee037ce0d3327eda1f`: per-result instrumented timing spans, pre-settlement immutable decode-length statistics, and rank-local PP timing metadata.
- This is a compatibility backport, **not** replacement of the engine with the complete PR head. Result-field placement is adapted to the older source layout; the timing module and DeviceTimer match the PR versions.
- No validation-only oracle D2H or extra timing-boundary events are included. The production changes add no D2H, CUDA events, kernels, or blocking synchronization; this does not establish zero CPU overhead or performance parity.
- Both architectures install [SemiAnalysis AIPerf](https://github.com/SemiAnalysisAI/aiperf/tree/754356e9a39acc6cc6afb242d123bb57c3fb6f75) at `754356e9a39acc6cc6afb242d123bb57c3fb6f75` in `/opt/agentx-aiperf`. Transitive dependencies resolve at build time and are recorded in `/opt/agentx-aiperf/freeze.txt`; engine dependencies remain separate.
- The disk recorder from [Dynamo PR #14511](https://github.com/ai-dynamo/dynamo/pull/14511), revision `1926d6ec765fcf7e86fc000a1b6a15b2b107e607`, is available at `/opt/fpm/recv_forward_pass_metrics.py`.
- FPM is not enabled image-wide. Enable it explicitly in the worker launch arguments; use the original engine Python and `/opt/agentx-aiperf/bin/aiperf` for the isolated client.
