## Interpretation

1. **Decode is close to the reference.** p90 ITL differs by less than 1%.
   Observed speculative acceptance-length gauge averaged ~2.9885, consistent
   with the configured synthetic target 2.99. This remains a performance-only
   experiment, not validation of model output quality.
2. **This is not a saturated-server throughput test.** AgentX c4 means four
   replay lanes, not four continuously active HTTP requests. Client effective
   concurrency averaged 0.7546 (p90 2, max 6); SGLang waiting-queue gauge
   averaged 0.0015 requests. There is no evidence of a large sustained queue.
3. **No-G2 is viable for this particular c4 replay.** Response-reported,
   token-weighted prompt reuse was 117,412,032 / 120,157,422 = 97.7152%.
   Only ~2.75 million of ~120.16 million prompt tokens were uncached. Reported
   total-token throughput includes cached prompt tokens and is not equivalent
   to executing 4166 new token computations/s/GPU.
4. **The lower TTFT is not an isolated G2 result.** The reference had HiCache on,
   but reported only 0.0184% CPU hits, alongside 98.2152% GPU hits. Our runtime
   is newer, adds a Dynamo frontend and has a larger GPU KV pool (1,961,024
   versus 1,704,256 tokens). The one-hour closed-loop runs also complete
   different request sets: mean input length 188,334.5 versus 183,323.1 tokens,
   and mean output length 1295.6 versus 1303.7. None of these differences was
   controlled in a paired A/B experiment. Cache-hit aggregation between the
   response export and reference server telemetry is only approximately comparable.

The data support a useful baseline with reference-like decode latency, not a
causal claim that disabling HiCache halves TTFT, nor a maximum-capacity claim.

## Timing and harness caveats

The exported wall-clock range is 16:26:58.479533–17:27:28.480554 PDT,
approximately **3630 seconds**: 3600 seconds of sending plus a 30-second credit
grace timeout. All 638 wire requests were already complete at the end of the
measured window. Dividing exported token totals by exported throughput also
recovers ~3630 seconds, whereas `benchmark_duration.avg` is 3598.7799 seconds
(the request activity span). Do not use these denominators interchangeably.
The reference's published throughput denominator is ~3602.7158 seconds.
The extra drain slightly depresses our reported throughput; it does not explain
the much lower TTFT. Keep the original metrics rather than silently removing it.

Raw logs retain a pending-future join warning and 36 tracked child states during
harness shutdown. Dataset preparation also reported failure to populate an
optional mmap cache due to local space, while runtime dataset construction and
profiling succeeded. The harness accepted the submission, but these warnings
should be retained when evaluating strict reproducibility.
