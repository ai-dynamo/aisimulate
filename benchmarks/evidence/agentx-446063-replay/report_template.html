How to read the replay

Choose a replay variant, then switch between Profiling and Warmup. Warmup includes the primer and ten live requests.

  • Hover to inspect values. Drag inside a chart to zoom; double-click to reset. Use the expand icon for a full-size view and the chart toolbar to export PNG.
  • Distribution / In-flight avg, P75 / P90, TTFT / E2E, and queue / throughput controls change the plotted metric.
  • Request timeline groups work by conversation or worker. Click a request to inspect its timestamps, lengths, status, and source identity.
  • Charts use seconds since the selected phase began. Original absolute virtual timestamps remain in exported data.
  • Missing metrics remain unavailable. No unique in-flight prompt count can be inferred from retained cache occupancy.
  • Aggregates retain request matching, coverage, and the distinction between request MAPE and one-point APE.

The complete one-hour benchmark replay used no new GPU measurements. Recorded output lengths match the reference workload where available; prompt tokenization still differs.
